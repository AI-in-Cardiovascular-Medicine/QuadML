# Contributing

## Report a bug or ask a question

1. Check [Troubleshooting](../getting-started/08-troubleshooting.md) first.
2. Note **mode**, install type (Windows / macOS / Linux / source), and the exact error or dialog text.
3. Open an issue on the public docs repository: [AI-in-Cardiovascular-Medicine/QuadML issues](https://github.com/AI-in-Cardiovascular-Medicine/QuadML/issues/)

Contacts and citation: [About QuadML](../getting-started/10-about.md).

## Documentation changes

User manuals are edited in the application project and published to the public **QuadML** documentation repository. Prefer clear, non-coder wording on user Pipeline / Results / Tutorial pages; put code layout, pins, and packaging under **For developers**.

Related pages: [Code structure](code-structure.md) · [Python requirements](python-requirements.md) · [Build and package](build-and-package.md)

## Application source

The public GitHub **QuadML** repository hosts **documentation only**. Access to the full application source (if you are a contributor) is arranged separately — see [ai-cvm.org/quadml](https://ai-cvm.org/quadml/) and [About QuadML](../getting-started/10-about.md).
