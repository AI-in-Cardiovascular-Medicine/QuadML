# About QuadML

**QuadML: A General-Purpose, Open-Source Executable Machine Learning Framework for Tabular Data**

QuadML lets you build, compare, and explain machine-learning pipelines on tabular data without writing code. It covers four tasks (classification, regression, survival analysis, and clustering) and searches the combinations of preprocessing and models you select, then reports metrics, plots, and explanations. All analyses run locally; no data is uploaded.

**Developed by:** The AI in Cardiovascular Medicine Laboratory ([AI-CVM](https://ai-cvm.org/)), Bern University Hospital, University of Bern, Switzerland

**Authors:** Hamed Mirzakhani, Giovanni Baj, Pooya Mohammadi Kazaj, Chaimae Bahou, Ali Hashemi Gheinani, Christoph Gräni, and Isaac Shiri
