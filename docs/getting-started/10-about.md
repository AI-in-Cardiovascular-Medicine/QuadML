# Getting started — About

**QuadML: A General-Purpose, Open-Source Executable Machine Learning Framework for Tabular Dataset**

QuadML lets you build, compare, and explain machine-learning pipelines on tabular data without writing code. It covers four tasks (classification, regression, survival analysis, and clustering) and automatically searches every combination of the preprocessing steps and models you select, then reports metrics, plots, and model explanations. All analyses run locally on your computer; no data is uploaded.

**Developed by:** The AI in Cardiovascular Medicine Laboratory ([AI-CVM](https://ai-cvm.org/)), Bern University Hospital, University of Bern, Switzerland
